# VCG Beat Universe

**Status:** APPROVED (2026-07-31)  
**What this is:** The closed set of beat types and the rules for assigning them.  
**Portable:** Import and use anywhere (Masterbeater, script critique, writer tools). Does not depend on graphics, layouts, edit techniques, or render systems.

A beat type answers only: **what job does this moment do for the viewer?**

---

## Rules

1. **Closed set.** Only the types below. Never invent a type for one video.
2. **Flat.** One field, one choice. No nesting.
3. **One primary type per span.**
4. **Cannot name it honestly → not a beat.** Sparse is correct.
5. **Never reintroduce:** `source-led`, `source-led-motion`, `section-label`, or comedy-jargon `tag` (use `aftershock` or `callback`).

---

## Decision order

When two labels could fit:

1. Unambiguous instructional form → `example` | `prompt` | `list` | `structure` | `ui`
2. Else narrative job → `hook` | `setup` | `punchline` | `aftershock` | `callback` | `proof` | `context` | `cta`
3. Else → no beat

---

## Types (13)

| ID | Job | How to spot it |
| --- | --- | --- |
| `hook` | Open a curiosity gap the viewer must keep watching to close | Bold promise, question, or mid-video open loop (“we’ll get to that”) **without** full payoff yet |
| `setup` | Baseline assumption before a twist | “Normal world,” wrong expectation, calm premise before the land |
| `punchline` | Main land / reinterpretation that pays off **now** | Joke payoff or sharp thesis that resolves the setup |
| `aftershock` | Immediate secondary punches after the main punchline | Rapid follow-ups on the **same bit**, no new premise, right after the main land |
| `callback` | Return to earlier material **later** | Explicit reference to an earlier joke, proof, hook, or line |
| `proof` | Hard fact / metric / credential hit | Dollars, percentages, ranks, time saved, named result |
| `context` | Background, definition, stakes — **no** open loop | Why it matters / what it is, without teasing unfinished payoff |
| `cta` | Drive a specific viewer action or destination | Subscribe, follow, link, next video, community |
| `example` | Numbered or named worked case | “Example 1…”, “First way…”, concrete case intro |
| `prompt` | AI prompt, command, or short code gist | “Use this prompt…”, recited syntax, command language |
| `list` | Multi-item sequence meant as sequential visual rows | “Three things…”, numbered items that each deserve a moment |
| `structure` | System view: process, stack, pathway, tradeoff | Pipeline, X vs Y, ordered model — not a flat tip list |
| `ui` | Point at on-screen software | “Click here…”, “this panel…”, named UI during screen share |

## Disambiguation

| Speech | Type |
| --- | --- |
| Open or mid-video unfinished tease | `hook` |
| Define / explain with no tease | `context` |
| Payoff now | `punchline` |
| Extra hits immediately after main punch | `aftershock` |
| Returns to something earlier | `callback` |
| Number / rank / $ / % | `proof` |

| | `aftershock` | `callback` |
| --- | --- | --- |
| When | Right after the main punchline | Later in the piece |
| Relation | Same bit, more hits | Reuses earlier material |

---

## Out of this universe

These are **not** beat types (other concerns may handle them elsewhere):

- Silence / pause timing  
- Cut techniques (smash cut, L-cut, J-cut)  
- Peak “button” energy without a content job  
- B-roll / footage choice  
- Camera moves, shaders, registry blocks, graphic template names  

---

## Change control

- Add, rename, or remove a type only with explicit creator approval.
- Superseded names stay listed under Rules (5); do not silently rewrite history.
