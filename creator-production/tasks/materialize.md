# Manifest materialization task

Using the locked transcript, channel-neutral analysis ledger, resolved channel
profile, capability catalog, and explicit admitted implementation records,
produce one complete `episode-manifest` JSON document.

Cover the entire absolute locked-source frame timeline without gaps. Chapters
must be completed editorial sections; elapsed duration may not create, split,
truncate, pad, or merge a chapter.

Every sequence must explicitly record semantic intent, presentation and
narrative roles, topology, capability bindings, assets, implementation set,
composition graph, decision receipt, and unresolved reasons. Every adjacent
boundary must explicitly be `none`, `hard-cut`, or a named admitted transition.
Every required asset must have an exact private path, content hash, media type,
and approved rights receipt. Missing or unknown rights block materialization;
never substitute a placeholder or an unlicensed search result.
Copy the semantic plan's `editorialDirective` without modification. For
authored and hybrid sequences, set `selectedVisualFamilyId` to the selected
source capability ID. Bind every visible editorial beat to exactly one graph
element through `properties.editorialBeatId`; its `properties.text` must equal
the planned on-screen copy exactly. Its reveal event must use the planned source
word and reveal frame, reach full visibility on the planned frame, and exit on
the planned exit frame. Recipe defaults and empty waiting containers are not
acceptable substitutes for planned editorial content.
Every authored `meaningfulChanges` item must bind to an actual graph event at
the same absolute frame through `event.parameters.meaningfulChangeId`. A
sequence boundary or an unrendered declaration is not a meaningful change.
Copy source-evidenced changes and intentional carries exactly from the semantic
plan; never manufacture, fragment, or move their evidence.
For a named transition, exactly one adjacent sequence owns the transition
capability binding and that binding must list its exact `eventIds`. Those events
must fall inside the boundary's declared duration window. Do not describe a
transition in boundary metadata without materializing the corresponding graph
events.
Record the exact profile token paths, fonts, policies, thresholds, preferences,
and reference-grammar fields consumed by every sequence. Do not claim the whole
profile when only a subset affected the sequence.
Every composition graph must contain the locked speaker source as a
`speaker-source` element, either full-screen or in an explicit container.
No visibility gap may exceed the Production profile's maximum speaker absence.
Every event that can change element geometry (`move`, `scale`, `enter`, or
`exit`) must include its normalized post-event rectangle in
`parameters.resolvedGeometry`; safety gates evaluate those exact rectangles at
the sequence boundaries, every classified source-layout boundary, every
inspected layout evidence frame, and every composition event frame. The source
layout classifier chooses only an OBS layout ID; use the host-resolved geometry
from the frozen source-evidence ledger and never redraw or reinterpret it.

Every content-bearing event must use an exact locked word start frame or a
measured source-event frame. Do not invent offsets. Do not substitute a weaker
compiled capability when the stronger valid fit requires adaptation; record
the unresolved adaptation instead.

Do not write source code or rendered media. Do not invoke another workflow.
